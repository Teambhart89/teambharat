# SEO Machine skills

The 26 marketing/SEO skills in this directory come from
[TheCraigHewitt/seomachine](https://github.com/TheCraigHewitt/seomachine)
(`.claude/skills/`), vendored at upstream commit `e818d5e`.

They are used unmodified, except that upstream's stray
`growth-lead-SKILL.md` was moved into `growth-lead/SKILL.md` so Claude Code
discovers it like the rest.

Installed skills:

| Skill | Focus |
| --- | --- |
| ab-test-setup | Experiment design, sample size, test templates |
| analytics-tracking | GA4 / GTM setup, event and conversion tracking |
| competitor-alternatives | "vs" and "alternative" comparison pages |
| content-strategy | Topic planning, clusters, editorial direction |
| copy-editing | Multi-pass editing of existing marketing copy |
| copywriting | Writing and rewriting page copy |
| email-sequence | Drip, onboarding, nurture, re-engagement flows |
| form-cro | Non-signup form conversion optimization |
| free-tool-strategy | Engineering-as-marketing free tools |
| growth-lead | Direct senior-growth-advisor strategy guidance |
| launch-strategy | Product / feature launch planning |
| marketing-ideas | 139 categorized marketing plays |
| marketing-psychology | 70+ mental models applied to marketing |
| onboarding-cro | Post-signup activation and time-to-value |
| page-cro | Conversion optimization for marketing pages |
| paid-ads | Google, Meta, LinkedIn, X campaign strategy |
| paywall-upgrade-cro | In-app paywalls, upgrade and upsell screens |
| popup-cro | Popups, modals, overlays, banners |
| pricing-strategy | Pricing research, tiers, packaging |
| product-marketing-context | Builds the shared product context doc |
| programmatic-seo | Template-driven pages at scale |
| referral-program | Referral, affiliate, word-of-mouth programs |
| schema-markup | JSON-LD structured data |
| seo-audit | Technical and on-page SEO diagnosis |
| signup-flow-cro | Signup, registration, trial activation |
| social-content | Platform-specific social content and repurposing |

Several skills reference a `.claude/product-marketing-context.md` file for
company positioning. Run the `product-marketing-context` skill once to create
it so the rest have shared context to draw on.
