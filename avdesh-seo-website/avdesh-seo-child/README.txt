AVDESH SEO CHILD THEME
======================

Use this child theme to add your own custom CSS or PHP without losing
changes when the main Avdesh SEO theme is updated.

HOW TO USE
----------
1. First install and (optionally) activate the parent theme "Avdesh SEO".
   The parent must be present in wp-content/themes for the child to work.
2. Install this child theme:
   Appearance > Themes > Add New > Upload Theme > choose avdesh-seo-child.zip
3. Click Activate. Your site looks identical, but now:
   - Add custom CSS in this theme's style.css
   - Add custom PHP in this theme's functions.php
   Both are safe from parent theme updates.

Note: all pages, menus and demo content are created by the PARENT theme on
its first activation, so activate the parent once before switching to the
child if you want the automatic setup to run.
