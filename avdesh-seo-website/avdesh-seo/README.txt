=========================================================
 AVDESH SEO - WordPress Theme
 SEO & AI Search Optimization Specialist website
 Version 1.0.0
=========================================================

Thank you for using the Avdesh SEO theme. This is a fast, fully responsive
and SEO friendly WordPress theme built to match your portfolio design, with a
cream, navy and warm orange colour scheme and Poppins typography.

It ships with a complete website: a portfolio style homepage, an About page,
a Services hub and eight dedicated service pages, plus Contact and Blog, all
with clean SEO friendly URLs, semantic H1 to H4 headings, schema markup and
image upload sections you control from the Customizer.


---------------------------------------------------------
 1. HOW TO INSTALL (2 minutes)
---------------------------------------------------------

Option A - Upload the ZIP (recommended)
  1. Log in to your WordPress admin dashboard.
  2. Go to  Appearance  >  Themes  >  Add New  >  Upload Theme.
  3. Choose the file  avdesh-seo.zip  and click  Install Now.
  4. Click  Activate.

That is it. On activation the theme automatically:
  - Creates every page (Home, About, Services + 8 service pages, Contact, Blog)
  - Gives each page a clean SEO friendly URL (for example /seo-services/)
  - Sets the homepage and the blog page
  - Builds the navigation menu with a Services dropdown
  - Turns on pretty permalinks

Option B - Manual install
  1. Unzip the file.
  2. Upload the  avdesh-seo  folder to  /wp-content/themes/  via FTP.
  3. Activate it from  Appearance > Themes.


---------------------------------------------------------
 2. ADD OR REPLACE IMAGES (no code needed)
---------------------------------------------------------

Anywhere you see a dashed box that says "Upload or replace this image",
you can add your own photo from the Customizer:

  Go to  Appearance  >  Customize  >  Images (upload / replace)

Available image slots:
  - Hero portrait (homepage top)
  - About section photo
  - Contact / footer profile photo
  - Case study images 1 to 4
  - Results / campaign images 1 and 2
  - SEO services, Technical SEO and AI search page images

Recommended sizes:
  - Hero and profile portraits: about 800 x 900 px
  - Case study images: about 600 x 400 px

To add your logo:  Appearance > Customize > Site Identity > Logo.


---------------------------------------------------------
 3. EDIT YOUR BUSINESS DETAILS
---------------------------------------------------------

Go to  Appearance  >  Customize  >  Business Details  to set:
  - Full name and professional title
  - Phone (display and dialable)
  - Email address and location
  - LinkedIn and WhatsApp links

These update the header, footer, contact page and schema automatically.

Homepage stat numbers (500%, 8+, and so on) are under
  Appearance  >  Customize  >  Homepage Stats Bar.


---------------------------------------------------------
 4. EDIT PAGE CONTENT
---------------------------------------------------------

All service page content is written for SEO and for readers, with full
H1 to H4 headings and FAQ sections. The core service copy lives in the
theme templates so the design stays consistent. To adjust wording you can
edit the matching file in the theme, for example:

  page-seo-services.php            /seo-services/
  page-technical-seo-services.php  /technical-seo-services/
  page-on-page-seo-services.php    /on-page-seo-services/
  page-off-page-seo-link-building.php  /off-page-seo-link-building/
  page-local-seo-services.php      /local-seo-services/
  page-ecommerce-seo-services.php  /ecommerce-seo-services/
  page-ai-search-optimization.php  /ai-search-optimization/
  page-google-ads-management.php   /google-ads-management/

Tip: keep a child theme if you plan heavy edits, so updates are easy.


---------------------------------------------------------
 5. CONTACT FORM
---------------------------------------------------------

The Contact page includes a ready to use form. For a professional inbox
integration, install a plugin such as Contact Form 7 or WPForms, then paste
its shortcode into the Contact page content. It will automatically replace
the default form.


---------------------------------------------------------
 6. SEO NOTES
---------------------------------------------------------

Built in SEO features:
  - Clean, keyword targeted SEO friendly URLs
  - One H1 per page with a logical H2, H3, H4 structure
  - Meta description, Open Graph and Twitter tags
  - Schema markup: ProfessionalService, Person, Breadcrumb and FAQ
  - Fast, responsive, mobile first layout
  - Content optimized for search engines and AI answer engines (GEO)

Recommended next steps:
  - Install an SEO plugin such as Rank Math or Yoast for per page titles
    and sitemaps (the theme works alongside them).
  - Connect Google Search Console and Google Analytics 4.
  - Submit your sitemap to Google.


Questions or tweaks? Everything here is standard WordPress, so any developer
can extend it easily.

Enjoy your new website.
