IMAGES — HOW TO ADD & REPLACE
=================================

This theme shows every image spot as a dashed "upload image" box until you add
your own picture. There is nothing to edit in code. You replace images in two
easy ways:

1) MAIN IMAGES (hero, about, social share) — via the Customizer
   ------------------------------------------------------------
   WordPress Dashboard  ->  Appearance  ->  Customize  ->  "Site Images"
   Upload:
     - Hero portrait (home top)
     - About section photo
     - About page secondary photo
     - Social share image (Open Graph, 1200x630)
   Click "Publish". The dashed boxes are instantly replaced with your images.

2) PORTFOLIO, CASE STUDY, BLOG & LOGO IMAGES — via the page / media library
   -------------------------------------------------------------------------
   - Blog & page featured images: edit the page/post -> set "Featured image".
   - Portfolio project images and brand/tool logos are marked with a dashed
     "Project image" / "Logo" box on the Portfolio and Home pages. To swap them
     for real pictures, open the matching template file and replace the
     placeholder block with an <img> tag, OR rebuild those sections with the
     block editor once your images are uploaded to Media.

RECOMMENDED IMAGE SIZES
   - Hero / About portrait: 800 x 1000 px (portrait)
   - Portfolio project image: 800 x 600 px
   - Brand / tool logos: 240 x 120 px (transparent PNG)
   - Social share (Open Graph): 1200 x 630 px
   - Certification badges: 300 x 300 px

TIP: compress images (TinyPNG, Squoosh) before uploading. Fast images improve
Core Web Vitals and your SEO.
