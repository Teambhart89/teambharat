# Avdesh Kumar — SEO Website (WordPress Theme)

A complete, ready-to-upload WordPress theme for **Avdesh Kumar, SEO & AI Search
Optimization Specialist (Delhi, India)**. The design matches the uploaded
portfolio (cream background, marigold orange accent, bold lowercase headings,
Poppins + Caveat fonts, numbered service cards, dark stats bar).

## 📦 The deliverable

**`avdesh-seo.zip`** — upload this in WordPress via
**Appearance → Themes → Add New → Upload Theme → Activate**.

On activation it auto-creates all pages, the navigation menu, and clean
SEO-friendly URLs. No page builder needed.

## ✨ What's included

- **17 pages**, each with a keyword-rich, SEO-friendly URL.
- **10 service pages** with full **H1 → H2 → H3 → H4** structure and
  reader-friendly, white-hat, GEO-optimized content.
- **AI-search ready:** Schema.org (Person, Service, FAQPage), Open Graph,
  quotable answer structure for ChatGPT, Gemini, Perplexity & Google AI Overviews.
- **Responsive** and fast, with clearly marked **image-upload sections**.
- **Customizer** for contact details, social links, images and homepage stats.
