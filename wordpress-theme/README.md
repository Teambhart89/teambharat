# Avdesh Kumar — Premium SEO Consultant Website (WordPress Theme)

A premium, conversion-focused WordPress theme that positions **Avdesh Kumar** as a
world-class freelance **SEO, AI Search Optimization (AISO), GEO & Google Ads
consultant** in Delhi, India. Modern international-agency design: deep navy base,
indigo → violet gradients, emerald growth accent, Sora + Inter typography, animated
counters, data-viz graphs and sticky contact buttons.

## 📦 The deliverable

**`avdesh-seo.zip`** — upload in WordPress via
**Appearance → Themes → Add New → Upload Theme → Activate**.
It auto-creates all pages, the navigation menu and clean SEO-friendly URLs.
